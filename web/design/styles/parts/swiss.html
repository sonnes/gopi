Swiss Brand

A figure is a poster on a strict grid: 2px rules, square corners, big bold numerals, and four flat colors, where fill, outline, hatching and dash tell the kinds apart.

Borrows from the International Typographic Style and from the landing page: butter yellow, brown ink, square corners, and the solid offset shadow of the primary action.

F1 · Streams

Reads as: a numbered table of events, with one column for each block, where the butter bar and the hatched bar show which block each delta feeds and how "Hel" becomes "Hello". Cost: the two lane columns take half the width, so a stream with three or more blocks needs narrower lanes or a second table.

F2 · Sessions

Reads as: one column for each message, with the kind set by fill (assistant), outline (user), hatching (meta) and dash (ephemeral), and the two new lines on disk raised by the butter fill and the offset shadow. Cost: the four kinds rely on the word in each tile as much as on the texture, because a dashed outline and a solid outline are close at a glance.

F3 · Tools

Reads as: the frame is the run, the thick loop stays inside it and goes back to the model, and the coral arrow breaks through the frame and leaves. Cost: hand-placed SVG with fixed text widths, so a longer type name means moving boxes by hand.

On a Page

A tool reports a failure in one of two ways. If the model can fix the call, return an error result with IsError set. The model reads it and tries again. If the run cannot go on, return a Go error. The run stops and Run returns the error to you.
