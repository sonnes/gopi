Borrows from Go by Example, with the code on the left and the notes on the right, and from a printout that a reviewer marked up with a pen.

Reads as: the file on disk after the call, with a + on each new line, a struck line for the time, and a bar for what the model reads. Cost: the kinds are told apart only by the words in each line, so the reader reads each line to find its kind.

F3 · Tools · two failure channels

Reads as: the two return lines of a real tool, where one leader climbs back to Run and the other drops out below the function. Cost: the loop is a direction on the page and not a drawn cycle, so the note must say "calls Run again".

On a Page · F3 next to body text

A tool can fail in two ways. If the model can correct the problem, return a result with IsError set and a nil error. The model reads the result and calls the tool again. If the run cannot go on, return a Go error. The agent stops the run and returns the error to the caller.

Reads as: a code block from the page with two pen marks, so the figure and the example code are one thing. Cost: the figure is 468px tall, which is taller than a drawn diagram of the same two paths.
