Plain Text

Every figure is monospaced text drawn with box-drawing characters, so a reader can select it and copy it.

Borrows from RFC diagrams, Go source comments, and the diagrams in docs/concepts/.

F1 · Streams

Reads as: a trace with one lane per block, where each delta lands on its lane and the text grows row by row. Cost: the lanes stop at tool_end, so the Wait rows have to repeat both blocks.

F2 · Sessions: Add Context to a Run

Reads as: a table where each argument of the call keeps its row, and the kind appears as a word and as a hue. Cost: "new" and "not stored" are short words at the right edge, so a skimming reader can miss them.

F3 · Tools: Two Failure Channels

Reads as: a railroad diagram with one track that bends back to the model and one that leaves. Cost: the loop spans the full width, so a longer result type or label does not fit in 72 columns.

On a page

A tool reports a problem with an error result or with a Go error. The model reads an error result as a normal tool result. Then the model corrects the call, and the run continues. A Go error is for a problem that the model cannot correct, for example a canceled context. A Go error stops the run.
