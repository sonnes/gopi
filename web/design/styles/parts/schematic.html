Schematic

Draw each figure as an engineering drawing: thin right-angle wires on a dot grid, uppercase lettering, and one signal colour for what is live.

Borrows from the drafting sheet (frame, corner ticks, title block), the logic-analyser timing diagram, and the circuit schematic.

F1 · Streams · timing diagram, one trace per ContentIndex

Reads as: a logic-analyser capture, where each pulse is one event, each row is one ContentIndex, the bus under it grows from Hel to Hello, and the message crosses the Wait line instead of pulsing on it. Cost: the event names must be angled to fit eight ticks in the column, and a reader who has never seen a timing diagram must learn that a pulse is an event.

F2 · Add Context to a Run · register view, one row per entry

Reads as: a register dump where each entry is a line that is high while it exists, so the new entries rise at the read and the time falls before the store. Cost: the kinds rest on four small glyphs and a dashed trace, which is less loud than a colour per kind, and the balloons ask the reader to match numbers from the code to the rows.

F3 · Two Failure Channels · routing diagram with a feedback wire

Reads as: a circuit with one output pin wired back to the input and the other wired off the sheet, so loop against exit is the route of the wire, not a word. Cost: the loop runs the full width of the sheet, so the figure is wide and short and leaves little room for a third outcome.

On a page · F3 under body text

A tool can fail in two ways, and the agent treats them differently. If your function returns an error, DefineTool turns it into a result with IsError set. The model reads that result and tries again. If Run returns a Go error, the run stops and a.Run returns that error to you.
