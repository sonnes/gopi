One Question Per Page, One Form Per Question

Each figure on the site comes from the question that its page answers. Option A of each slot is the form that the site uses. Each form is a component in web/src/components/figures/. B and C are the forms that were not chosen. They stay here as a start for the next page. Each figure is drawn at the width of the docs column (566px). The theme button switches between light and dark.

"What is inside it?"Anatomy: annotated code, signature brackets, nesting, two faces.
"In what order?"Time: lanes, spans, tapes, transcripts, replay tables.
"Which one applies?"Comparison: check matrices, forks, ladders, spec sheets.
