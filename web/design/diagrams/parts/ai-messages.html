Messages

Must get across: a conversation is a list of messages, each a role with typed content blocks, and every call sends the whole list.

Today: four stacked boxes with the blocks as pipe-separated text, so it reads like a schema and not like a conversation, and the tie from a tool call to its result is a plain arrow.
