Providers

Must get across: each provider is one package that calls one API, implements a fixed set of interfaces, and maps the shared ai settings onto that API's own fields.

Today: all three pages open with the same flowchart, an options list and a models list with arrows into ai.LanguageModel. It is a list drawn as boxes. The thinking, server, and caching facts sit in tables and prose with no picture.
