A tool has info that the model reads, and a run function that you call with a tool call. A middleware is a function that takes a tool and returns a tool. Package `tool` holds both. The info, the call, and the result are in package `ai`.

`tool.New` turns an error from your function into an error result. A canceled or expired context stays a Go error. A raw tool can return a Go error for a middleware, such as a retry. The agent then gives the text of the error to the model.

## What Out Becomes

| Out             | Result                          |
| --------------- | ------------------------------- |
| `string`        | One `Text` block                |
| `ai.ToolResult` | Passed through                  |
| Any other type  | JSON text in one `Text` block   |

## Options

| Option                 | Sets                                                                  |
| ---------------------- | --------------------------------------------------------------------- |
| `tool.Description(s)`  | The description that the model reads to decide when to call the tool |
| `tool.InputSchema(s)`  | The schema of the input. `tool.New` derives it, so only `tool.Func` needs it |
| `tool.Sequential()`    | The calls of a message with this tool run one after another |
| `tool.Deferred()`      | The tool waits until an `ai.ToolAdded` block in a [system message](../ai/messages.mdx#system-messages) adds it |

`tool.New` and `tool.Func` take the same options. `tool.Defer(t)` marks a tool that is already built, such as a tool from another package, as deferred. An agent loads a deferred tool with its search. [Tool Changes](../agent/tool-changes.mdx) shows how.

[Use Tools](../guides/use-tools.mdx) shows three middlewares.

```go
func Reminder(text string) tool.Middleware {
	return func(next tool.Tool) tool.Tool {
		return tool.Wrap(next, func(ctx context.Context, call ai.ToolCall) (ai.ToolResult, error) {
			res, err := next.Run(ctx, call)
			if err == nil {
				res.Content = append(res.Content, ai.Text{Text: text})
			}
			return res, err
		})
	}
}
```
