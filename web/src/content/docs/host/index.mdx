An [agent](../agent/index.mdx) runs while your program holds it. A host runs the messages of each session one at a time, holds each tool call that needs a person, and reports each change of the status. Without a host, you start each driver and keep the status of each session yourself.

## Create a Session

Register a driver for each CLI in the catalog, and the harness as the default driver. Then open a host on a store, and create a session with a config. One host owns each store.

```go
file, _ := catalog.ReadModelFile(ctx, "models.json")
cat := catalog.New()
cat.RegisterDriver("claude-code", claude.Driver(), file.Of("claude-code")...)
cat.DefaultDriver(harness.New(harness.Catalog(cat)))

h, err := host.Open(ctx, cat, host.Store(store), host.Sections(review))
defer h.Close()
s, err := h.Create(ctx, host.Config{
	Model: "claude-code/claude-opus-5-5",
	Dir:   repoDir,
	Deny:  []string{"Bash(git push:*)"},
})
```

The host calls `review` before each run for the [sections](../agent/sections.mdx) of a session. `anthropic/claude-opus-5-5` runs the same model in the harness. If the file does not have the model of a spec, call `cat.FetchDriverModels(ctx)` before `Create`.

## Create an Agent From a Folder

`Agent` names an agent file in the `agents/` folder of `Dirs`:

```go
s, err := h.Create(ctx, host.Config{
	Dirs:  []string{teamDir, repoDir},
	Agent: "reviewer",
	Dir:   repoDir,
})
```

The model, the mode, and the effort of the file fill the empty fields of the config, and an edit of them changes only a new session. If two dirs have the agent, the later dir wins. The host reads the prompt of the file before each run. The harness also reads the skills and the subagents of `Dirs`.

## Send a Message

`Send` returns when the session takes the message.

```go
err := h.Send(ctx, s.ID, host.Text("Review the diff against main."))
```

| Status of the session | The message                                                        |
| --------------------- | ------------------------------------------------------------------ |
| `idle`                | runs at once                                                       |
| `running`             | steers the run before its next model call                          |
| `running`, Codex agent | runs after the run, because Codex cannot steer                    |

`h.Interrupt(ctx, id)` cancels the active run, and a message that waits runs next.

## Confirm a Tool Call

A tool call that needs a person makes the status `requires_action`, and `Session.Waiting` has each call that waits. Answer each call by its ID, in any order:

```go
for _, req := range s.Waiting {
	allow := req.Call.Name == "Read"
	err := h.Confirm(ctx, s.ID, req.Call.ID, agent.Decision{Allow: allow})
}
```

A call waits until `Confirm` or the end of its run, and after the run `Confirm` returns `host.ErrNotFound`. A call has the tool name of its agent, such as `Bash` in Claude Code and `bash` in the harness.

The `Mode` of the config decides the calls that need a person. With `agent.ModeAcceptEdits`, an edit runs and a command asks. With `agent.ModeBypass`, no call asks. If no person answers, confirm from `Events`, or pick a mode that asks for no call.

## Change a Session

`Update` changes the model, the effort, the mode, or the rules of a session. The next run starts the agent again from the new config.

```go
s, err := h.Update(ctx, s.ID, func(c *host.Config) {
	c.Model = "claude-code/claude-sonnet-5-5"
	c.Mode = agent.ModePlan
})
```

An active run ends with its old config. `Update` returns `host.ErrInvalid` for a model of another kind of agent, and for a change of the folders or the agent file.

## Follow the Host

`Events` gives each session, and then each change. Each event has the whole session.

```go
_, events := h.Events(ctx)
for e, err := range events {
	if err != nil {
		return err
	}
	fmt.Println(e.Session.ID, e.Session.Status, e.Session.StopReason)
}
```

A run ends with the status `idle` and a stop reason: `end_turn`, `interrupted`, `error`, or `restarted`. A run that the end of the program cut short reads as `restarted` after the next `Open`.

## Follow a Session

`h.Stream` gives the [state](../agent/events.mdx) of the agent of one session, and then the events of each of its runs. It also works for a session with no agent.

```go
state, events, err := h.Stream(ctx, s.ID)
for ev, err := range events {
	if err != nil {
		return err
	}
	state.Apply(ev)
	fmt.Println(state.Streaming(), len(state.Messages()))
}
```

If a reader falls too far behind, its stream ends with `host.ErrSlowReader`. Call `Events` or `Stream` again.

A message that `Send` takes is never lost, and after a restart the next message starts the agent again from the stored config. The methods and their rules are in [GoDoc](https://pkg.go.dev/github.com/sonnes/gopi/pkg/host).
