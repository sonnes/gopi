## Two Ways to Read

To read only the message, call `Wait`:

```go
msg, err := stream.Wait()
```

To read each event, range over `Events`. Then call `Wait` for the message:

```go
for ev, err := range stream.Events() {
	if err != nil { return err }
	// ev.Type, ev.ContentIndex, ev.Delta, ev.Content, ev.ToolCall
}
msg, err := stream.Wait()
```

`Wait` returns the final message or the error that ended the call, even if you break out of `Events` early.

## Events

| Type                                            | Carries                             |
| ----------------------------------------------- | ----------------------------------- |
| `start`                                         | Nothing                             |
| `text_start`, `thinking_start`, `tool_start`    | `ContentIndex`                      |
| `text_delta`, `thinking_delta`, `tool_delta`    | `ContentIndex`, `Delta`             |
| `text_end`                                      | `ContentIndex`, `Content`           |
| `thinking_end`                                  | `ContentIndex`                      |
| `tool_end`                                      | `ContentIndex`, `ToolCall`          |

`ContentIndex` tells you which block a delta belongs to. A response with thinking and text has two blocks, so a UI keeps one buffer for each index. To show each kind of block in its own place, switch on the event type:

```go
switch ev.Type {
case ai.EventThinkDelta:
	fmt.Fprint(os.Stderr, ev.Delta)
case ai.EventThinkEnd:
	fmt.Fprintln(os.Stderr)
case ai.EventTextDelta:
	fmt.Print(ev.Delta)
case ai.EventTextEnd:
	fmt.Println()
}
```

## Thinking

The `ai.Thinking` option sets the thinking level. The provider maps the level to its own parameter.

```go
stream := model.StreamText(ctx, messages, ai.Thinking(ai.ThinkingMedium))
```

A thinking block comes back signed, and the API verifies the signature. Append the whole assistant message to the next turn, and do not edit the block:

```go
messages = append(messages, *msg, ai.UserMessage("And half of that?"))
msg, err = model.StreamText(ctx, messages, ai.Thinking(ai.ThinkingMedium)).Wait()
```

[Anthropic](../providers/anthropic.mdx), [OpenAI](../providers/openai.mdx), and [OpenAI Chat](../providers/openai-chat.mdx) give the levels that each provider maps. ChatGPT and OpenRouter use the levels of OpenAI. Fireworks uses the levels of OpenAI Chat.

## Forward to a Browser

An event round-trips through JSON with the zero fields omitted, so a text delta is one small object.

```go
func forward(w *json.Encoder, ev ai.Event) error {
	return w.Encode(ev)
}
```

```json
{"type":"text_delta","content_index":1,"delta":"outine"}
```

A handler that serves server-sent events calls `forward` for each event. Then it sends the message from `Wait` as the last frame.

## Rules

- A stream has one consumer, on one goroutine.
- A break out of `Events` does not stop the producer. It runs to its end, and the stream drops the later events. To stop a call, cancel the context.
- An error from before the request comes on the stream. There is one error path.
