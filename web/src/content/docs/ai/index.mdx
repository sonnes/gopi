`pkg/ai` holds the types that name a model call. A provider serves the call. A binding pairs a model with a provider. The messages go in, and a stream of events and one final message come out.

## The Optional Capabilities

A provider always streams text. It can also do these. `ai.GenerateObject` and `ai.CountTokens` are functions that take a language model and assert the interface on its provider. If the provider lacks the interface, the function returns an error. Images and speech have their own bindings, `ai.ImageModel` and `ai.SpeechModel`. Each binding takes only a provider that implements its interface, so a binding to a provider without it does not compile.

A provider can also list the models that its key can call, with `ModelLister`. The list belongs to the provider and not to one model, so it is a method on the provider and not a function on the binding. Every provider in this repository implements it.

The pages for [Anthropic](../providers/anthropic.mdx), [OpenAI](../providers/openai.mdx), [OpenAI Chat](../providers/openai-chat.mdx), [OpenRouter](../providers/openrouter.mdx), [Fireworks](../providers/fireworks.mdx), and [ChatGPT](../providers/chatgpt.mdx) show what each provider adds to a call.

## Count the Tokens

`ai.CountTokens` takes the same messages and options as the call. So the count is what the call sends, with the system prompt.

```go
count, err := ai.CountTokens(ctx, model, messages, system)
fmt.Println("input tokens:", count.Total)
```

## Ask for a Typed Value

`ai.GenerateObject` derives a JSON schema from a struct and sends it. Then it decodes the answer into the struct. The model reads the `jsonschema` tag as the description of a field.

```go
type Recipe struct {
	Name        string   `json:"name"`
	Ingredients []string `json:"ingredients"`
	Minutes     int      `json:"minutes" jsonschema:"total time in minutes"`
}

res, err := ai.GenerateObject[Recipe](ctx, model, messages)
fmt.Printf("%s, %d minutes\n", res.Object.Name, res.Object.Minutes)
fmt.Println("raw:", res.Raw)
```

`res.Object` is the decoded struct. `res.Raw` is the JSON text that the model wrote. If the provider does not implement `ai.ObjectProvider`, the call returns an error before any request.
