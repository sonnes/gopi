A model is one named model that a provider serves. It holds an ID, a name, its limits, the kinds of input that it reads, its thinking levels, and its prices. It holds no credentials. A provider is one backend that answers a call. It holds the credentials and speaks the wire format. A binding pairs the two, and your code calls the binding.

## Bind

```go
model := ai.LanguageModel{
	Model:    ai.Model{ID: "claude-sonnet-5"},
	Provider: anthropic.New(),
}
```

The same model value binds to any provider that serves it. The same provider serves any of its models.

`ai.GenerateObject` and `ai.CountTokens` are package functions that take the binding as an argument. [The Optional Capabilities](index.mdx#the-optional-capabilities) says which providers implement them.

## Get the Full Model

A model with only its `ID` works with its provider. Its other fields are zero, and a zero field is unknown. Its cost is zero until it has `Pricing`.

The file [models.json](../../../../../models.json) holds the full model of each ID that a provider or a driver serves. `make models` writes it from the model lists of the providers and from models.dev. Your program reads the file with `catalog.ReadModelFile`, from a path or an http or https URL. The function keeps no cache. Your program picks where the file comes from and when to read it again.

```go
file, err := catalog.ReadModelFile(ctx, "models.json")
m, ok := file.Lookup("openrouter", "moonshotai/kimi-k3")
```

A catalog takes the models of the file. `env.Detectors(file)` registers the models of each provider that has a key. `RegisterDriver` takes the models of a driver, such as `file.Of("claude-code")`, and `RegisterModel` adds one model. With the zero file, a detector registers no models, and a spec resolves only after `FetchModels`.

```go
c := catalog.New()
c.Detect(env.Detectors(file)...)
lm, err := c.LanguageModel("claude-sonnet-5")
```

The gopi CLI reads the file from `$GOPI_MODELS`, a path or a URL. If `$GOPI_MODELS` is not set, it reads `$GOPI_HOME/models.json`. If `$GOPI_HOME` is not set, it reads `~/.gopi/models.json`. Without the file, a spec resolves after the CLI asks the provider for its models.

## Read the Metadata

A call without `ai.MaxTokens` uses the output cap of the model. If the model has no cap, the call uses the default of the provider. The other fields are for your code: pick a model that reads PDFs, check a request against the context window, or offer only the thinking levels that a model takes. [GoDoc](https://pkg.go.dev/github.com/sonnes/gopi/pkg/ai#Model) lists the fields.

The provider prices each response from `Pricing`, so the usage of a message holds its cost:

```go
msg, err := model.StreamText(ctx, messages).Wait()
fmt.Printf("$%.4f\n", msg.Usage.Cost.Total())
```

`Pricing.CacheWrite` is the price of a write to the default cache of the provider. `Pricing.CacheWriteLong` is the price of a write to the long cache that `ai.CacheLong` asks for.

## Other Bindings

`ai.ImageModel` and `ai.SpeechModel` follow the same pattern with `ImageProvider` and `SpeechProvider`. The [OpenAI](../providers/openai.mdx) provider implements `ImageProvider`. No provider in this repository implements `SpeechProvider`.
