The messages are the only argument of a call. Every other setting, such as the system prompt or the tools, travels as an option. A [system message](messages.mdx#system-messages) adds to the prompt from its place in the conversation.

## The Built-In Options

| Setter              | Type                | Default when unset                         |
| ------------------- | ------------------- | ------------------------------------------ |
| `ai.SystemPrompt`   | `[]ai.Content`      | No system prompt                           |
| `ai.Tools`          | `[]ai.ToolInfo`     | No tools                                   |
| `ai.MaxTokens`      | `int`               | `Model.MaxTokens`, then the provider's own |
| `ai.Thinking`       | `ai.ThinkingLevel`  | The default of the model                   |
| `ai.Temperature`    | `float64`           | The default of the model                   |
| `ai.ToolChoice`     | `ai.ToolChoiceMode` | The model decides                          |
| `ai.CacheRetention` | `ai.Retention`      | `ai.CacheShort`                            |
| `ai.MaxRetries`     | `int`               | No retry                                   |
| `ai.MaxRetryDelay`  | `time.Duration`     | 60 seconds                                 |
| `ai.Headers`        | `map[string]string` | No extra headers                           |

The system prompt is a list of blocks. An `ai.Text` block is plain text, and an `ai.Section` block is a named part of the prompt:

```go
ai.SystemPrompt([]ai.Content{
	ai.Text{Text: "You are terse."},
	ai.Section{Name: "date", Text: "Today is 2026-10-07."},
})
```

A provider retries only before the first event of a stream, and only after an error that can pass, such as a rate limit. If the server asks for a wait longer than `ai.MaxRetryDelay`, the call fails at once. A provider does not send `ai.Temperature` to a model that rejects it.

## Your Own Option

A provider defines an option with `NewOption`, once, at package level. It travels in the same list as the built-in ones, and no other provider sees it.

```go
var Upper = ai.NewOption[bool]()

// in the provider
if upper, ok := ai.GetOption(opts, Upper); ok && upper { ... }
```

`openai.PromptCacheKey` is one. [OpenAI](../providers/openai.mdx) shows it, and [Write a Provider](../guides/write-a-provider.mdx) shows one in a program.
