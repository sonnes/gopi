Add an option when a call needs a system prompt, tools, retries, or a setting other than the default. Without options, each setting takes the default in the table below. A [system message](messages.mdx#system-messages) adds to the prompt from its place in the conversation.

## The Built-In Options

| Setter              | Sets                                        | Default when unset                         |
| ------------------- | ------------------------------------------- | ------------------------------------------ |
| `ai.SystemPrompt`   | The system prompt, as a list of blocks      | No system prompt                           |
| `ai.Tools`          | The tools that the model can call           | No tools                                   |
| `ai.MaxTokens`      | The cap on the output tokens                | `Model.MaxTokens`, then the provider's own |
| `ai.Thinking`       | How much the model reasons                  | The default of the model                   |
| `ai.Temperature`    | The sampling temperature                    | The default of the model                   |
| `ai.ToolChoice`     | If the model must call a tool, and which one | The model decides                         |
| `ai.ImageSize`      | The size of each image                      | The API picks the size                     |
| `ai.ImageCount`     | The number of images                        | The API picks the number                   |
| `ai.CacheRetention` | How long the provider keeps the cached prefix | `ai.CacheShort`                          |
| `ai.MaxRetries`     | The number of retries of a call             | No retry                                   |
| `ai.MaxRetryDelay`  | The cap on the wait that a server asks for | 60 seconds                                 |
| `ai.Headers`        | More HTTP headers for the request           | No extra headers                           |

[GoDoc](https://pkg.go.dev/github.com/sonnes/gopi/pkg/ai) gives the type of each setter.

The system prompt is a list of blocks. An `ai.Text` block is plain text, and an `ai.Section` block is a named part of the prompt:

```go
ai.SystemPrompt([]ai.Content{
	ai.Text{Text: "You are terse."},
	ai.Section{Name: "date", Text: "Today is 2026-10-07."},
})
```

A provider retries only when you set `ai.MaxRetries`, and never after the first event of the stream. The error must be one that can pass, such as a rate limit. If the server asks for a wait longer than `ai.MaxRetryDelay`, the call fails at once. The Anthropic provider does not send `ai.Temperature` to a model that rejects it, or when thinking is on. The OpenAI providers send it when you set it.

## Your Own Option

A provider defines an option with `NewOption`, once, at package level. It travels in the same list as the built-in ones. A provider that does not read it ignores it.

```go
var Upper = ai.NewOption[bool]()

// in the provider
if upper, ok := ai.GetOption(opts, Upper); ok && upper { ... }
```

`openai.PromptCacheKey` is one, and the OpenAI Chat provider reads it too. [OpenAI](../providers/openai.mdx) shows it, and [Write a Provider](../providers/write-a-provider.mdx) shows one in a program.
