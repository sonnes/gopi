`StreamText` returns a stream. `Events` gives each delta as it arrives. `Wait` gives the final message after the last event. If you only need the message, call `Wait` alone.

```go
for ev, err := range stream.Events() {
	if err != nil {
		log.Fatal(err)
	}
	fmt.Print(ev.Delta)
}

msg, err := stream.Wait()
```

## Tell the Blocks Apart

Switch on the event type. `ContentIndex` says which block the delta belongs to, so a UI keeps one buffer per index.

```go
switch ev.Type {
case ai.EventThinkDelta:
	fmt.Fprint(os.Stderr, ev.Delta)
case ai.EventThinkEnd:
	fmt.Fprintln(os.Stderr)
case ai.EventTextDelta:
	fmt.Print(ev.Delta)
case ai.EventTextEnd:
	fmt.Println()
}
```

## Forward to a Browser

An event marshals to JSON with the zero fields omitted, so a text delta is one small object.

```go
func forward(w *json.Encoder, ev ai.Event) error {
	return w.Encode(ev)
}
```

```json
{"type":"text_delta","content_index":1,"delta":"outine"}
```

A handler that serves server-sent events calls `forward` for each event, then sends the message from `Wait` as the last frame.

## Ask for Thinking

The level travels as an option. The provider maps it to its own parameter.

```go
stream := model.StreamText(ctx, messages, ai.Thinking(ai.ThinkingMedium))
```

A thinking block comes back signed. Append the whole assistant message to the next turn. Do not edit the block, or the provider rejects the signature.

```go
messages = append(messages, *msg, ai.UserMessage("And half of that?"))
msg, err = model.StreamText(ctx, messages, ai.Thinking(ai.ThinkingMedium)).Wait()
```

## Read the Output

- The thinking goes to stderr and the text to stdout. Run it with `2>/dev/null` to see only the answer.
- `Wait` after the loop returns the final message. It holds both blocks.
- The thinking block is signed. The second turn sends it back and the model continues from it.
