## Models

The package has no models. Use an `openai` model for OpenAI, or write your own for another server. Set `MaxTokens`, because Fireworks caps a call at 2048 tokens by default.

```go
kimi := ai.Model{
	ID:        "accounts/fireworks/models/kimi-k2-thinking",
	Name:      "Kimi K2 Thinking",
	MaxTokens: 16384,
}
p := openaichat.New(
	openaichat.APIKey(os.Getenv("FIREWORKS_API_KEY")),
	openaichat.BaseURL("https://api.fireworks.ai/inference/v1"),
)
lm := ai.LanguageModel{Model: kimi, Provider: p}
```

A thinking block goes back as `reasoning_content`. A model with interleaved thinking needs it between tool calls. Send the assistant message back unchanged.

## Objects

`ai.GenerateObject` uses a strict JSON schema response format. On Fireworks, the schema turns off the reasoning output.

## Errors

An API error wraps `openaichat.Error`. An error that OpenRouter reports after the stream starts fails the stream. With `ai.MaxRetries`, the provider retries before the first event, as the [Anthropic](anthropic.mdx#errors) provider does.

## Tool Results With Files

The Chat API takes only text in a tool result. The provider sends the text as the result, and each image in a user message after the results.
