## Thinking

`ai.Thinking` maps to the reasoning effort of the API. A level that the provider does not know fails the call before the request.

<Ladder

The API stores nothing. A thinking block carries the encrypted reasoning in its signature. Send the assistant message back unchanged, and the model keeps its reasoning between tool calls.

## Caching

The mark goes only to GPT-6 and GPT-5.6, because other models reject it. Put the stable part of a prompt first. `openai.PromptCacheKey` routes the calls of one conversation to the same cache. `ai.CacheLong` keeps the prefix for 24 hours, and `ai.CacheNone` sends no mark and no key. `Usage.CacheRead` and `Usage.CacheWrite` show the effect.

```go
opts := ai.JoinOptions(
	ai.SystemPrompt(system),
	openai.PromptCacheKey(conversationID),
)
```

## System Messages

GPT-6 and GPT-5.6 take a developer message in the conversation, and the provider sends a system message there. A tool that a system message adds goes in place as an `additional_tools` item, so the cached prefix stays the same. A tool that a system message removes stays in the tool list, and an `allowed_tools` tool choice limits the model to the current tools. Every other model gets the text as a `<system-reminder>` in a user message.

## Objects

`ai.GenerateObject` uses structured outputs in strict mode. The schema comes from your struct.

## Token Counts

`ai.CountTokens` sends the same input, tools, and thinking config as a call. Only api.openai.com has the endpoint.

## Images

`GenerateImage` takes `openai.GPTImage2` or a GPT Image 2.5 model, with `ai.ImageSize` and `ai.ImageCount`.

```go
im := ai.ImageModel{Model: openai.GPTImage2, Provider: openai.New()}
resp, err := im.GenerateImage(ctx, "A blue circle", ai.ImageSize("1024x1024"))
```

## Other Servers

`BaseURL` points the provider at another Responses API. OpenRouter serves one at `https://openrouter.ai/api/v1`. It has no token count and no images. For Fireworks, use [OpenAI Chat](openai-chat.mdx).

## Errors

An API error wraps `openai.Error`. Read the status code with `errors.As`. With `ai.MaxRetries`, the provider retries before the first event, as the [Anthropic](anthropic.mdx#errors) provider does.
