## Models

Name a model by the ID of the API, such as `ai.Model{ID: "gemini-3.8-flash"}`. [models.json](../../../../../models.json) holds the limits and prices of each ID in the figure. `ListModels` gives each model that the key can call with `generateContent`. `env.Detectors` registers the provider when `GOOGLE_API_KEY` or `GEMINI_API_KEY` is set.

## Thinking

`ai.Thinking` maps to the thinking level of the API. Gemini 3 and Gemini 4 always think, so `ThinkingOff` sends the lowest level. The API rejects a level that the model does not take.

The API stores nothing. A thinking block carries the thought signature of the model. Send the assistant message back unchanged, and the model keeps its reasoning between tool calls.

## System Messages

The input of the API has no system role. `ai.SystemPrompt` goes to the system instruction of the request. A system message in the history goes as a `<system-reminder>` in a user turn.

## Options

The provider does not send `ai.Temperature`. A tool choice of one tool sends the mode `any` with that tool as the only allowed tool.

## Objects

`ai.GenerateObject` sends the schema of your struct as a JSON response format.

## Images

`GenerateImage` takes a Nano Banana model, with `ai.ImageSize` and `ai.ImageCount`. The image models take the sizes `1K`, `2K`, and `4K`. One request gives one image, so `ai.ImageCount(3)` sends three requests.

```go
im := ai.ImageModel{Model: ai.Model{ID: "gemini-nano-banana-2.1"}, Provider: gemini.New()}
resp, err := im.GenerateImage(ctx, "A blue circle", ai.ImageSize("1K"))
```

## Decisions

`Decide` sends a [decision](../ai/decisions.mdx) to the Decisions API of Gemini, at `/decisions` under the base URL and the API version of the Go SDK. The API version of the SDK is `v1beta` today, so the path is `/v1beta/decisions`. The decision model is `gemini-decision-1`. The API reads text, images, PDF documents, audio, and video. It has no box question. For a box question or a file of another type, the provider returns an error that wraps `errors.ErrUnsupported` before the request.

The API reads no tool calls, tool results, or thinking blocks. So the provider sends a tool call as text, such as `[tool call read_file] {"path":"a.go"}`, and a tool result as text that names its tool. It drops each thinking block. A safety block is a `*gemini.Error` with the status 400.

## Errors

A failed answer of the API is a `*gemini.Error`. Read the status code with `errors.As`. With `ai.MaxRetries`, the provider retries before the first event, as the [Anthropic](anthropic.mdx#errors) provider does.
