## The Log

`a.Log()` returns the log of an agent. The log of `agent.New` is in memory. `agent.Durable` opens the log in a store, so a later process resumes it.

```go
a, err := agent.Durable(ctx, model, "user-42", agent.Store(store))

entries := a.Log().Entries() // every stored entry, in append order
msgs := a.Log().Messages()   // what the model reads
```

A session has one writer. Two logs on one session interleave their entries, and a provider can reject the result.

## Entries

An entry holds one message, or the data of a custom entry. The log sets its ID and its time.

```go
session.Text("hi", session.Author("user-42"))
session.Text("The time is 9:14 AM.", session.Ephemeral())
session.NewEntry(msg, session.Author("importer"))
custom, err := session.Custom("compaction", summary)
```

To add entries, pass them to `Run`, `Steer`, or `FollowUp` of the [agent](../agent/index.mdx), or return them from an `AfterTurn` or `BeforeStop` [hook](../agent/hooks.mdx).

The author is a user ID or an agent name. The `Name` option of an agent sets the author of each entry that the agent writes. For context that must stay, such as a skill, give the entry an author of its own. The store keeps it, and your UI can skip that author.

A custom entry of the kind `gopi`, or of a kind that starts with `gopi.`, belongs to gopi.

## Values

A value has a namespace, a key, and a type. Declare it once, then read and write it through the log. The store keeps it as JSON, and a later `Set` replaces it.

```go
var title = session.Value[string]{Namespace: "app.title"}

err := title.Set(ctx, a.Log(), "Trip to Lisbon")
t, ok, err := title.Get(a.Log())
err = title.Delete(ctx, a.Log())
```

`Read` gets a value from a `session.Snapshot`, before you open the session. [`session.Value`](https://pkg.go.dev/github.com/sonnes/gopi/pkg/session#Value) has each method.

```go
snap, err := store.Load(ctx, "user-42")
t, ok, err := title.Read(snap)
```

The JSONL store can repair the file in `Load`, so call `Load` only when no other process writes the session.

A key names one value in a namespace, such as a label for each entry: `session.Value[string]{Namespace: "app.label", Key: entryID}`. The namespace `gopi` and each namespace that starts with `gopi.` belong to gopi.

## In a Hook

A hook reads the session from `State.Log()`. It can set and delete values, and it cannot append an entry. An `AfterTurn` or `BeforeStop` hook returns entries, and any hook can queue them with [`s.Steer` or `s.FollowUp`](../agent/hooks.mdx#steer-from-a-hook).

```go
var turns = session.Value[int]{Namespace: "app.turns"}

count := agent.AfterTurn(func(ctx context.Context, s agent.State) ([]session.Entry, error) {
	n, _, err := turns.Get(s.Log())
	if err != nil {
		return nil, err
	}
	return nil, turns.Set(ctx, s.Log(), n+1)
})
```

A value is in the store when `Set` returns, also if the run fails after it.

## After a Crash

A crash loses at most the message in flight. It can leave a tool call with no result, and a provider rejects that.

## Stores

| Store                      | Keeps                              | Use it for                 |
| -------------------------- | ---------------------------------- | -------------------------- |
| `session.NewMemoryStore()` | Maps in process memory             | Tests. `Durable` uses it when you set no `Store` |
| `storefs.Sessions(dir)`    | One append-only file per session   | One process on one machine |

For a service, implement [`session.Storer`](https://pkg.go.dev/github.com/sonnes/gopi/pkg/session#Storer) over your database.

## The JSONL File

The file of a session is `<dir>/<id>.jsonl`. The first line is the record. Each line after it is one entry or one value write. The store never rewrites a line.

- A custom entry is a `message` line too.
- Each set adds a line, and the load replays the value lines in order.
- If a complete line does not decode, the load fails.
- An ID that holds `/` or `\`, or that is `.` or `..`, is an error.
