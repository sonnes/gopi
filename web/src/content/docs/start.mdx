<Steps>

1. Add the module. gopi needs Go 1.27 or later.

   ```sh frame="none"
   go get github.com/sonnes/gopi
   ```

2. Set the key. The Anthropic provider reads it from the environment.

   ```sh frame="none"
   export ANTHROPIC_API_KEY=sk-ant-...
   ```

3. Save the program and run it.

   <Code code={hello} lang="go" title="examples/hello/main.go" />

   ```sh frame="none"
   go run .
   ```

</Steps>
