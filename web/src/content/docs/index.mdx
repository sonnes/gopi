## Host

`pkg/host` runs the lifecycle of each session over its workspace: the status, the calls that wait for a person, and the recovery after a restart.

Use it for a product that runs many sessions, a page where a person approves tool calls, or sessions that come back after a deploy. Skip it when one program runs one session, and use `agent.Durable`.

[Read about the host](host/index.mdx)

## Harness

`pkg/harness` turns a repository into an agent. Each part of the agent is an option: the model, the instruction files, skills, subagents, MCP servers, tools, and the permission rules.

Use it for a coding agent, or for an agent that a team changes through files. Skip it when the code gives the tools and the prompt and reads no files, and use `agent.New`.

[Read about the harness](harness/index.mdx)

## Agent

`pkg/agent` runs the loop: a model call, the tool calls, and the hooks at each point, until the model stops. Claude Code and Codex run as agents too.

Use it for your own loop in your process, on any provider, with hooks around each call. Skip it when one model call needs no tools, and use `StreamText`.

[Read about agents](agent/index.mdx)

## Session

`pkg/session` keeps the log of a session in a store. Each message is stored before its event, so a crash loses at most the message in flight.

Use it for a record of the work that outlives the process, and for app state next to the messages. An agent with `agent.Store` writes the log, so a program seldom calls this layer.

[Read about sessions](session/index.mdx)

## Tool

`pkg/tool` turns a Go function into a tool with a typed input. A middleware wraps each call, and a deferred tool loads only when the model searches for it.

Use it for each function that the model can call. For the tools of an MCP server, give the server to `harness.MCP`.

[Read about tools](tool/index.mdx)

## Model Call

`pkg/ai` makes one model call: messages and options in, a stream of events and a message out. Each provider plugs into this layer.

Use it for one reply, a summary, a label, or a typed value with `ai.GenerateObject`. Skip it when the model calls tools in a loop, and use `pkg/agent`.

[Read about model calls](ai/index.mdx) · [Providers](providers/anthropic.mdx)

## Catalog

`pkg/catalog` resolves a model spec, such as `anthropic/claude-opus-5-5`, to a provider or to the driver of an agent. Skip it when the code builds an `ai.LanguageModel` itself. [GoDoc](https://pkg.go.dev/github.com/sonnes/gopi/pkg/catalog) has its calls.

## Start

gopi is a root module and one module for each provider. Import the packages that your program uses, then run `go mod tidy` to add their modules. gopi needs Go 1.27 or later. [Model Call](ai/index.mdx) ends with a program that makes the first call.

Every signature and field is in [GoDoc](https://pkg.go.dev/github.com/sonnes/gopi). The design rules of each part are in [Concepts](../../../../docs/concepts/README.md).
