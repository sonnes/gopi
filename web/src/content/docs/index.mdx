gopi is a Go SDK for AI agents. It gives you one call to a model, tools that a model can call, and the events of a call as a stream.

## One Call

<AnnotatedCode
  alt="The call lines of the hello program in three steps. Step 1 binds a model to a provider. Step 2 builds the messages. Step 3 reads the stream with Wait."
  steps={[
    {
      code: `model := ai.LanguageModel{
\tModel:    anthropic.Sonnet5,
\tProvider: anthropic.New(),
}`,
      title: "bind",
      type: "ai.LanguageModel",
      note: "Model + Provider",
    },
    {
      code: `messages := []ai.Message{
\tai.UserMessage("Say hello in one sentence."),
}`,
      title: "build",
      type: "[]ai.Message",
      note: "+ ai.Options, if any",
    },
    {
      code: `msg, err := model.StreamText(ctx, messages).Wait()
if err != nil {
\tlog.Fatal(err)
}
fmt.Println(msg.Text())`,
      title: "read",
      type: "Wait() → *ai.Message",
      note: "Events() gives the deltas",
    },
  ]}
/>
